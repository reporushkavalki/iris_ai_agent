WELCOME TO IRIS

Your crypto control room, running only on this computer. Connect what you use; every section appears as soon as it has data.

  1. Press TRY DEMO DATA to look around with made-up numbers (nothing real is read).
  2. Open Connections and add a read-only exchange API key, or paste a public wallet address.
  3. Optionally add your social accounts to track followers, likes and views.
  4. Add your Claude API key to chat with Iris about your numbers.
Never paste a seed phrase or private key anywhere. Iris only ever reads.
